# 基于 Web 的校园信息交流论坛系统

一个面向校园场景的移动端优先论坛项目，支持图文发帖、匿名互动、内容推荐、行为画像、数据分析和管理员治理。

项目最初是为 `qianxian.site` 站点持续迭代而来，已经在真实服务器环境中完成上线、功能扩展和性能优化。

## 项目简介

传统校园信息传播经常依赖朋友圈、QQ群、微信群或校园墙代发，这类方式传播快，但也存在信息沉淀差、搜索困难、互动分散、后台治理弱等问题。

本项目围绕“校园交流 + 内容治理 + 数据分析”三个方向进行设计，实现了一个可部署、可演示、可继续扩展的校园论坛系统。

## 核心功能

### 用户端

- 手机号注册登录
- 昵称必填、头像上传或默认头像选择
- 图文发帖
- 无标题发帖自动生成标题
- 匿名发帖
- 帖子按发布时间倒序展示
- 帖子详情页独立展示
- 点赞、评论、匿名评论
- 评论图片上传
- 我的帖子
- 收到回复

- 站内通知
- 精选内容
- 推荐栏目
- 行为画像
- 数据分析页

### 管理端

- 首页轮播图管理
- 公告弹窗设置
- 论坛左上角图标配置
- 用户搜索
- 用户禁言
- 匿名帖子真实身份查看
- 站内数据统计与行为分析

### 数据与安全

- 敏感词检测
- 骂人词/辱骂词检测
- 禁言拦截
- 用户行为日志采集
- 规则化推荐
- 数据可视化统计
- 图片上传压缩

- Service Worker 静态资源缓存，提升弱网访问稳定性

## 技术栈

- Frontend: HTML / CSS / JavaScript
- Backend: PHP
- Database: MySQL
- Deployment: Ubuntu + BT Panel
- Runtime optimization: PHP-FPM + OPcache
- Client optimization: Request dedupe / timeout / short cache / Service Worker

## 本地运行方法

### 1. 准备运行环境

需要准备以下环境：

- PHP 8.x
- MySQL 5.7+ 或 8.x
- 支持静态资源访问的 Web 服务器
- 推荐启用 PHP `gd` 扩展，用于图片压缩

### 2. 配置数据库

先创建数据库，例如：

```sql
CREATE DATABASE forum_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

然后根据你的实际表结构导入基础表，或者执行项目中的迁移脚本补充字段与索引：

- `api/migrate_forum_comments_media.sql`
- `api/migrate_forum_like_unique.sql`
- `api/migrate_user_behavior_logs.sql`

### 3. 配置接口连接

将 `api/config.example.php` 复制为 `api/config.php`，然后填写自己的数据库配置。

示例：

```php
$host = getenv('DB_HOST') ?: 'localhost';
$dbname = getenv('DB_NAME') ?: 'forum_db';
$user = getenv('DB_USER') ?: 'forum_user';
$pass = getenv('DB_PASS') ?: 'change_me';
```

### 4. 启动站点

将项目放入站点根目录后，保证以下路径可访问：

- `/index.html`
- `/css/*`
- `/js/*`
- `/api/*`
- `/h5/index.html`

同时保证上传目录具备写权限：

```text
/uploads/forum/
```

## 使用说明

### 普通用户使用流程

1. 注册账号并填写昵称
2. 进入首页浏览内容
3. 点击底部中间发布按钮发帖
4. 可选择匿名发帖
5. 进入帖子详情页后评论，可选择匿名评论和上传评论图片
6. 在“我的”页面查看：
   - 行为画像
   - 数据分析
   - 我的帖子
   - 收到回复
   - 点赞过
   - 站内通知

### 管理员使用流程

1. 使用管理员账号登录
2. 进入“我的”页面中的管理员入口
3. 管理轮播图、公告和论坛图标
4. 搜索用户并进行禁言
5. 对匿名帖子点击“查看信息”查看真实身份与手机号
6. 通过后台统计页面查看帖子、评论、活跃用户和行为数据

## 部署说明

线上版本使用过以下部署方式：

1. 本地整理代码
2. 打包上传到服务器
3. 解压到发布目录
4. 通过宝塔面板管理站点
5. PHP 使用 OPcache 提升性能
6. 图片上传时自动压缩，减少带宽与磁盘占用

如果你也要部署：

- 推荐使用 Ubuntu
- 推荐使用 BT Panel 或 Nginx + PHP-FPM
- 推荐打开 OPcache
- 推荐限制上传大小并开启图片压缩

## 已完成的代表性优化

- 图片打开后支持放大、缩小、拖拽、移动端双指缩放

- 评论输入区改为点击后展开，减少页面杂乱
- 轮播图与公告从发布页拆分到管理员入口
- 首页帖子按时间顺序展示
- 新增推荐栏目与精选栏目
- 新增公开数据分析页
- 管理员可以查看匿名帖子真实身份
- 用户被回复后可在站内通知查看动态
- 注册时昵称改为必填
- 发帖支持不写标题
