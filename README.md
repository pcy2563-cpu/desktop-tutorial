# 基于 Web 的校园信息交流论坛系统

这是一个面向校园场景的移动端优先论坛项目，支持图文发帖、匿名互动、评论图片、内容推荐、行为画像、数据分析、公告弹窗和管理员治理。项目已部署到真实服务器环境，并围绕性能、图片压缩、权限校验和安全防护做了持续优化。

## 项目特点

- 用户可使用手机号注册登录，昵称为必填项。
- 发帖无需手动填写标题，系统会按内容自动展示。
- 支持匿名发帖、匿名评论、评论图片上传、点赞、帖子详情页和站内通知。
- 首页帖子按发布时间倒序展示，并提供推荐、精选、我的帖子、收到回复、点赞过等内容入口。
- 提供公开数据分析页，用可视化方式展示帖子、评论、活跃用户和行为数据。
- 管理员可维护轮播图、公告弹窗、论坛图标、用户封禁、匿名帖子真实信息查看等功能。
- 后端加入敏感词检测、骂人词检测、禁言拦截、登录令牌、管理员令牌、接口频率限制和上传格式校验。

## 技术栈

- 前端：HTML、CSS、JavaScript
- 后端：PHP
- 数据库：MySQL
- 部署：Ubuntu、宝塔面板、Nginx、PHP-FPM
- 优化：图片压缩、请求去重、短缓存、Service Worker、OPcache

## 本地运行

1. 准备 PHP 8.x、MySQL 5.7+ 或 MySQL 8.x。
2. 创建数据库，字符集建议使用 `utf8mb4`。
3. 将 `api/config.example.php` 复制为 `api/config.php`，填写数据库连接信息。
4. 导入基础表结构，并按需执行 `api/migrate_*.sql` 迁移脚本。
5. 将项目放入站点根目录，确保 `/uploads/forum/` 目录有写入权限。
6. 访问 `/index.html` 或 `/h5/index.html` 即可使用。

## 安全说明

仓库默认忽略以下内容，避免把敏感配置和部署产物上传到 GitHub：

- `api/config.php`
- `.env`
- `uploads/`
- `deploy-*`
- `*.zip`
- `*.tar.gz`
- `*.log`

线上环境应使用强密码，并定期更新服务器、宝塔面板、PHP、Nginx 和数据库版本。

## 管理员功能

管理员登录后可进入“我的”页面中的管理员入口，维护公告、轮播图、站点图标、用户封禁、数据统计和匿名帖子真实信息。后台操作已加入管理员令牌校验和操作日志，避免普通用户绕过前端直接调用接口。
