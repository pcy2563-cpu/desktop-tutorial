# qianxian.site

校园信息交流论坛项目，包含移动端优先的前端页面、PHP 接口、MySQL 数据存储，以及用户行为分析、推荐展示和后台治理功能。

## 主要功能

- 手机号注册登录、昵称与头像管理
- 图文发帖、无标题发帖、匿名发帖
- 帖子详情、点赞、匿名评论、评论图片上传
- 内容中心：我的帖子、收到回复、点赞过、站内通知
- 推荐栏目、行为画像、数据分析可视化
- 管理员功能：轮播图、公告、论坛图标、匿名信息查看、用户禁言

## 技术栈

- Frontend: HTML / CSS / JavaScript
- Backend: PHP
- Database: MySQL
- Deployment: Ubuntu + BT Panel

## 目录说明

- `index.html`: 主入口页面
- `h5/`: H5 同步页面资源
- `css/`: 样式文件
- `js/`: 前端逻辑与接口封装
- `api/`: PHP 接口与数据库迁移脚本

## 注意事项

- 仓库默认忽略部署产物、上传文件和本地配置文件。
- 运行前需要自行补充 `api/config.php` 等环境配置。
