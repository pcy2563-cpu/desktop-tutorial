# 浅显通校园论坛

一个面向校园场景的信息交流论坛系统，适合用于校园墙、班级社区、社团交流、二手交易、失物招领、活动通知和学习资料分享等轻量社区场景。

在线体验地址：[https://qianxian.site](https://qianxian.site)

## 项目定位

浅显通不是单纯的静态展示页，而是一个可以发布、互动、管理和分析数据的校园社区系统。用户可以发动态、上传图片、匿名发布、评论回复、点赞互动；管理员可以管理公告、轮播图、用户、举报内容和站内运营数据。

适合以下使用场景：

- 学校或班级搭建内部信息交流平台。
- 校园墙负责人从朋友圈发布方式升级为网站社区。
- 社团、组织、活动方集中发布通知和收集反馈。
- 学生作品展示、毕业设计演示、个人简历项目展示。

## 主要功能

### 普通用户

- 浏览校园动态信息流。
- 搜索帖子内容。
- 发布图文动态。
- 支持匿名发布。
- 支持图片上传和图片预览。
- 查看帖子详情。
- 评论、回复、点赞。
- 查看“我发”“我回”“我赞”“通知”等个人内容。
- 查看个人行为画像和数据分析。

### 管理员

- 发布和修改站内公告。
- 管理首页轮播图。
- 查看用户信息并进行禁言处理。
- 查看匿名帖真实发布者信息。
- 处理帖子和评论举报。
- 查看发帖、评论、点赞、浏览等运营数据。
- 通过后台入口维护社区内容。

### 内容治理

- 支持举报帖子和评论。
- 支持敏感词检查。
- 匿名内容对普通用户隐藏真实身份。
- 管理员敏感操作保留日志，方便追踪。

## 页面说明

- 首页：展示轮播图、搜索栏、内容信息流和帖子栏目。
- 发布页：发布图文动态，可选择匿名。
- 我的：登录、个人信息、我的内容、数据分析、管理员入口。
- 帖子详情页：查看完整内容、评论、图片、点赞和举报。
- 数据分析页：展示论坛内容和用户行为数据。
- 管理后台：公告、轮播、用户、举报等管理功能入口。

## 技术栈

- 前端：Vue 3、Vite、Vue Router、Pinia
- 后端：PHP API
- 数据库：MySQL
- 部署环境：Nginx、PHP-FPM、宝塔面板

说明：本版本前端是 Vue SPA，后端仍然使用 PHP 接口，因此部署时需要同时保留 `api/` 目录。

## 快速部署

1. 将本项目上传到网站根目录。
2. 复制 `api/config.example.php` 为 `api/config.php`。
3. 在 `api/config.php` 中填写 MySQL 数据库连接信息。
4. 导入数据库表结构和初始数据。
5. 确保 `uploads/` 目录可写。
6. 将 Nginx 网站根目录指向项目目录。
7. 配置 Vue Router history 回退到 `index.html`。
8. 访问网站首页，测试登录、发布、评论和后台功能。

Nginx history 回退示例：

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

以下内容属于服务器私有配置或用户上传数据，不应该提交到公开仓库：

- `api/config.php`
- `.env`
- `uploads/`
- `.well-known/`
- 数据库备份文件
- 服务器临时文件
- 任何账号密码、API Key、Token

## 适合展示的项目亮点

- 使用 Vue SPA 构建移动端优先的校园社区页面。
- 使用 PHP 和 MySQL 实现发帖、评论、点赞、通知等核心业务。
- 增加匿名发布和管理员真实身份查看机制，兼顾用户表达和后台治理。
- 增加举报、敏感词检查、禁言和管理员日志，提升内容安全性。
- 增加数据分析和行为画像，把普通论坛升级为可运营社区。
- 支持服务器部署，可作为真实网站访问，而不是只能本地运行的 Demo。
