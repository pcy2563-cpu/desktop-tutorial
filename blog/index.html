通用博客框架

把学习、项目和思考整理成长期可复用的内容资产

浅显博客是一个可直接作为项目上传 Git 的学习型博客模板。它支持文章、项目、技能树、笔记、感悟和成长时间线，但当前默认不预置任何个人内容。

模块入口

首页只做中枢，各模块独立展开

这里没有预置文章、项目和个人资料。当前展示的是一套完整的博客框架，后续内容都可以通过后台分模块自行上传和维护。

文章专栏

适合沉淀复盘、方法论和正式输出

默认没有任何预置文章。你可以后续自行发布项目复盘、课程总结、阅读记录和阶段思考。

项目仓库

用接近 Git 仓库的方式展示项目

项目页会按仓库风格展示状态、分支、更新时间、README 亮点和对外链接，更适合做作品集和展示型项目页。

技能树

用思维导图方式整理你的能力结构

默认没有技能节点。你可以后续将前端、后端、数据分析、部署等能力按分支逐步补充进去。

笔记资源库

点开像翻书一样阅读和整理笔记

笔记模块支持目录、章节和资源文件，但当前默认为空。后续你可以把课程笔记、项目文档和阅读整理都放进来。

学习台

保留一个轻量的学习进度中控区

这里不再放个人化路线图，而是保留一个空白学习台，方便后续扩展成课程跟踪、阶段目标和学习记录模块。

阶段感悟

像动态流一样记录不同阶段的想法

感悟区支持时间、地点、情绪和图片，但当前没有预置任何内容。后续可以作为个人成长记录、项目心路或阶段想法的时间流。

成长时间线

用时间维度串起阶段节点和内容入口

时间线可以联动感悟、项目和阶段记录。目前它作为空白框架存在，方便后续补充你的真实成长轨迹。

内容管理

分模块维护博客，不把所有内容挤在一个后台里

这里按文章、项目、技能树、笔记、感悟、时间线拆成独立标签页。当前默认内容为空，适合直接作为模板项目继续开发。
